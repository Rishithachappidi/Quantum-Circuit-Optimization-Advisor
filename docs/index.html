What the prediction means

The model estimates the probability of accepted measurement outcomes for a benchmark. Each algorithm has its own success definition. VQE and QAOA represent sampled ansatz circuits; QFT is a forward-and-inverse round trip.

Fidelity, execution time, error rate and the recommendation label are excluded from model inputs. Related optimization variants are kept in the same evaluation group.

Prediction coverage

Being inside a recorded qubit range does not guarantee accuracy on every circuit. Padded Bell and odd-size Simon registers are identified explicitly. No simulated or measured performance is invented for new choices.

Complete project flow

How a circuit becomes an optimization recommendation.

Source-backed workflow
01

Choose a quantum circuit

Nine built-in families with 2–10 total qubits. The same seed is used for each deterministic circuit.

02

Extract structural features

Depth, gate counts, qubit and classical width, gate density, and single- and multi-qubit operations.

03

Compare Qiskit candidates

Real Qiskit transpilation at optimization levels 0, 1, 2 and 3 for fully connected and linear profiles. Candidates are generated before publication.

04

Estimate success and noise exposure

Your saved Random Forest scores each built-in candidate. Gate and layer exposure respond to the selected noise profile.

05

Recommend a level

Keep predictions within 0.01 of the best, then prefer lower exposure, depth, gate count and optimization level.

About this browser edition

Built-in comparisons are computed with Qiskit and the original trained model before deployment. The public page loads these verified artifacts, so it needs no Python process, Joblib upload or simulator server. Changing noise and shots selects the matching model prediction and recomputes analytical exposure.

Custom circuits receive validated structural analysis only. This dashboard does not execute circuits on real hardware or run new noisy simulations. Existing model scores and dataset statistics remain separate from the expanded circuit catalog.
